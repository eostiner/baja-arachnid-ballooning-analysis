# Step 10I centerpiece map QA checklist

Review the freshly generated PDF or SVG at full size before manuscript submission.

- The title states C3 = D1-D3 versus fixed N0, with D4 excluded.
- All four dashed lines are described as **a priori test latitudes**, not demonstrated barriers.
- Sparse ecoregions are hatched using the actual `<8 eligible cells` rule.
- Each formal ecoregion has one donut, one expected classified-richness value, and one C3:N0 ratio label.
- Donut area represents equal-cell C3 + N0 richness from eight occupied cells.
- Orange and green wedges sum to the classified C3 + N0 assemblage; D4 is absent from the denominator.
- The latitude-band panel contains all five bands in south-to-north order.
- The 1:1 reference and the `higher N0` / `higher C3` directions are correctly oriented.
- Band values and intervals match `10I_band_ratio_summary.csv`.
- The note about Benjamini-Hochberg-corrected adjacent-band tests matches `10I_adjacent_band_ratio_tests.csv`.
- Ecoregion abbreviations and English names are legible and correct.
- No donut, label, legend, or coastline is clipped in the exported PDF/SVG.
- The new rendering is visually consistent with `docs/reference_figures/Figure_3_reference_2026-07-16.jpg`; only documented wording or fresh numerical changes should differ.

The map is a visual synthesis of prior analyses and does not add a new hypothesis test.
